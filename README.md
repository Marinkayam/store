# AcroShop 🤸‍♀️ — דף נחיתה לציוד אקרובטיקה

דף נחיתה מודרני שמציג מוצרים לעונת האקרובטיקה, עם קישורים לרכישה באלי אקספרס.
הדף סטטי לחלוטין (HTML/CSS/JS) — אין צורך בשרת, אפשר לארח בחינם ב-GitHub Pages.

## 📁 מבנה הפרויקט

| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה הדף (Hero, קטגוריות, פוטר) |
| `css/style.css` | כל העיצוב |
| `js/products.js` | **רשימת המוצרים — הקובץ היחיד שצריך לערוך!** ✏️ |
| `js/main.js` | הלוגיקה שמציירת את הכרטיסים, הסינון והחיפוש |

## ⭐ איך מוסיפים את קישורי האפיליאציה (חשוב!)

כרגע כל המוצרים מקושרים ל**קישורי חיפוש** באלי אקספרס — הם עובדים, אבל
**לא מזכים בעמלה**. כדי להרוויח עמלות:

1. נכנסים לפורטל השותפים: **https://portals.aliexpress.com**
2. מאתרים מוצר ספציפי — מומלץ דרך **Hot Products / High Commission**,
   שם רואים ליד כל מוצר את **אחוז העמלה (Commission Rate)**.
   כדאי לבחור מוצרים עם עמלה גבוהה (5%–9% ומעלה) ועם דירוג מוכר טוב.
3. מדביקים את קישור המוצר בכלי **Link Generator** בפורטל ומקבלים קישור
   אפיליאציה אישי (כולל ה-tracking ID שלך).
4. פותחים את `js/products.js` ומדביקים את הקישור בשדה `link` של המוצר.
5. מומלץ גם להעתיק את כתובת תמונת המוצר (קליק ימני על התמונה באלי
   אקספרס ← "העתק כתובת תמונה") ולהדביק בשדה `image` — ואז תוצג
   תמונת המוצר האמיתית במקום האימוג'י.

### הוספת מוצר חדש

מעתיקים בלוק קיים ב-`js/products.js` ומשנים את הפרטים:

```js
{
  name: "שם המוצר",
  desc: "תיאור קצר וכיפי",
  category: "hair",        // hair / clothing / training / gear
  emoji: "🎀",             // מוצג כשאין תמונה
  image: "",               // כתובת תמונה מאלי אקספרס (אופציונלי)
  link: "קישור האפיליאציה שלך",
},
```

## ⚡ אוטומציה: סנכרון אוטומטי מ-API של אלי אקספרס (מומלץ!)

במקום למלא כל מוצר ביד, אפשר לתת לסקריפט למשוך אוטומטית מאלי אקספרס את
**שם המוצר, התמונה, המחיר, אחוז העמלה ולינק האפיליאציה התקין** — לכל
הלינקים בבת אחת.

### מה צריך פעם אחת

1. **פרטי API** מפורטל השותפים:
   נכנסים ל-https://portals.aliexpress.com ← אזור **Open Platform / App
   Management** ← יוצרים אפליקציה ומקבלים **App Key** ו-**App Secret**.
   (ה-**Tracking ID** הוא מזהה השותף שכבר יש לך, מופיע תחת Account/Tracking IDs.)
2. מעתיקים את `tools/config.example.json` ל-`tools/config.json` וממלאים
   את שלושת הערכים. הקובץ `config.json` כבר ב-`.gitignore` ולא ייעלה לגיט.

### איך מריצים

1. מוסיפים את הלינקים (או מספרי מוצר) ל-`tools/products.input.json`.
   אפשר להשאיר `category` ריק — הסקריפט ינחש לפי שם המוצר.
2. מריצים (צריך **Node.js 18+**, בלי שום התקנת חבילות):

   ```bash
   node tools/aliexpress-sync.mjs
   ```

3. הסקריפט פותר כל לינק, מושך את הפרטים מה-API, וכותב מחדש את
   `js/products.js`. הוא גם **מתריע על מוצרים עם עמלה נמוכה מ-3%**
   כדי שתוכלי לבחור חלופות רווחיות יותר. פותחים את `index.html` ורואים. 🎉

### חשוב לגבי גישת רשת

הסקריפט ניגש לאינטרנט (אלי אקספרס). במחשב רגיל זה עובד מיד. אם מריצים
אותו בתוך סביבת **Claude Code on the web**, צריך להגדיר שם את
**Network access** לרמה שמתירה גישה לאלי אקספרס (הרמה הרחבה היא
האמינה ביותר — יש באגים ידועים ברשימות דומיינים צרות).

## 🚀 איך מעלים את הדף לאוויר (GitHub Pages)

3. תוך דקה הדף יהיה זמין בכתובת `https://<username>.github.io/store/`
