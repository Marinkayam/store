# התראות טלגרם — הקמה

פיצ'ר אופציונלי לגמרי. בלעדיו שום דבר לא נשבר — פשוט לא נשלחות התראות.
שני משתנים בוורסל, וזהו.

## מה שולח התראה

- **חנות חדשה נפתחה** — ברגע שנוצר החשבון בסוף האונבורדינג.
- **מישהי הצהירה ששילמה** — ממתינה לאישור שלך בחמ"ל.

## שלב 1 — יצירת הבוט

1. בטלגרם, לחפש **@BotFather** ולפתוח איתו צ'אט.
2. לשלוח לו `/newbot`.
3. לתת שם (למשל `דוכן התראות`) ואז שם משתמש שמסתיים ב-`bot` (למשל `duchan_alerts_bot`).
4. BotFather יחזיר טוקן שנראה כך: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — זה `TELEGRAM_BOT_TOKEN`.

## שלב 2 — מציאת ה-chat id שלך

1. לחפש את הבוט שיצרת (לפי שם המשתמש שנתת לו) ולפתוח איתו צ'אט.
2. לשלוח לו כל הודעה (למשל "היי").
3. בדפדפן, לפתוח את הכתובת הזו (להחליף `<TOKEN>` בטוקן משלב 1):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
4. בתשובה שמוחזרת (JSON), לחפש `"chat":{"id":` — המספר שאחריו הוא ה-`TELEGRAM_CHAT_ID`.
   אם הרשימה ריקה — לוודא ששלחת הודעה לבוט לפני שפתחת את הכתובת, ולנסות שוב.

## שלב 3 — וורסל

`Settings → Environment Variables`, לסמן Production, ואז `Deployments → Redeploy`:

```
TELEGRAM_BOT_TOKEN=<מה שקיבלת מ-BotFather>
TELEGRAM_CHAT_ID=<המספר מה-getUpdates>
```

## בדיקה

אחרי ה-Redeploy, לפתוח דוכן חדש (או להריץ את האונבורדינג בכל דפדפן) —
הודעה אמורה להגיע לצ'אט עם הבוט תוך שניות. אם לא הגיעה כלום — לוודא
שהמשתנים נשמרו על Production ושבאמת בוצע Redeploy אחרי ההוספה.
