# שחזור מגיבוי

הקרון היומי (`app/api/cron/route.ts`, 03:00) כותב את כל המסד לקובץ JSON אחד
ב-R2: `_backups/YYYY-MM-DD.json`. הקבצים נשמרים 30 יום ואז נמחקים.

## מה בקובץ ומה לא

- **בקובץ:** כל הטבלאות שברשימה `BACKUP` בקרון, ורשימת החשבונות (`auth_users`:
  מזהה, מייל, טלפון, מועד יצירה).
- **לא בקובץ, בכוונה** (`SKIPPED` בקרון, עם הסיבה לכל אחת): יומנים וקודים
  שמתיישנים, ומפתחות (`app_secrets`).
- **לא בקובץ בכלל:** תמונות וסרטונים. הם יושבים ב-R2 עצמו, והמסד מחזיק רק את
  הכתובות שלהם.

## איך משחזרים

```bash
node scripts/restore-backup.mjs <backup.json> <postgres-url>
```

| אפשרות | מה היא עושה |
|---|---|
| `--mode missing` (ברירת המחדל) | מוסיף רק שורות שחסרות. לא נוגע בשורה קיימת |
| `--mode overwrite` | גם מחזיר שורות קיימות למה שהיה בגיבוי |
| `--tables a,b` | רק הטבלאות האלה |
| `--dry-run` | מריץ הכול ומבטל בסוף, ומדפיס מה היה קורה |

הכול בטרנזקציה אחת: או שהכול נכנס, או ששום דבר.

### תרחיש 1: שורות נמחקו או שדות נדרסו בטעות

```bash
# קודם לראות מה ישתנה
node scripts/restore-backup.mjs 2026-11-20.json "$DB_URL" --tables orders --mode overwrite --dry-run
# ואז באמת
node scripts/restore-backup.mjs 2026-11-20.json "$DB_URL" --tables orders --mode overwrite
```

`overwrite` מחזיר את **כל** השורות בטבלה למצב של הגיבוי, כולל שינויים שנעשו
מאז. לתיקון של שורות בודדות עדיף לסנן את הקובץ קודם.

### תרחיש 2: המסד כולו אבד

1. מקימים פרויקט Supabase חדש ומריצים את כל המיגרציות (`npm run migrate`).
2. מקימים מחדש את החשבונות (ראה למטה).
3. `node scripts/restore-backup.mjs <backup.json> <postgres-url>`.

## מה נבדק ומה לא

- **נבדק אוטומטית** (`e2e-backup.mjs`, בכל הרצה של שרשרת הבדיקות): הגיבוי מכסה
  את כל הטבלאות, שחזור מלא למסד ריק נותן מסד זהה למקור שורה מול שורה, ותיקון
  נקודתי מחזיר שורות שנמחקו ושדות שנדרסו.
- **לא נבדק:** הקמה מחדש של החשבונות בפרויקט Supabase אמיתי. בסביבת הבדיקות
  `auth.users` היא טבלה פשוטה והסקריפט משחזר אליה. ב-Supabase אמיתי הסקריפט
  מדלג על החשבונות ומתריע, וצריך להקים אותם דרך ה-Admin API
  (`auth.admin.createUser` עם אותו `id` ואותו `email`) לפני שמשחזרים את שאר
  הטבלאות. כדאי לתרגל את זה פעם אחת על פרויקט ניסיון.
- **לא נבדק:** קריאת קובץ הגיבוי האמיתי מ-R2. הבדיקה רצה מול אחסון מקומי.
