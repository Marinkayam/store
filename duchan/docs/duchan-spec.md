# דוכן — מפרט מוצר מלא

> שם עבודה. "דוכן" = חנות קטנה שילדה מקימה בעצמה, לא Shopify מוקטן.
> גרסה 0.1 · מפרט לבנייה

---

## 1. מה זה

פלטפורמה שבה ילדה נרשמת לבד, מעלה מוצרים מהטלפון, מעצבת חנות משלה, ומקבלת לינק לשיתוף.
קונה נכנסת ללינק, בוחרת מוצרים, ולוחצת כפתור שפותח וואטסאפ עם ההזמנה מנוסחת מראש.
מכאן זו שיחה בין שתי ילדות. **המערכת לא נוגעת בכסף ולא במשלוח.**

**מה זה כן:** כלי ליצירת חנות ולניהול הזמנות.
**מה זה לא:** מערכת סליקה, מערכת מלאי, מרקטפלייס.

## 4. הרשמה

מסך אחד, 5 שדות:

1. שם החנות
2. הטלפון שלי (וואטסאפ)
3. השם והטלפון של אמא/אבא
4. אימייל של ההורה
5. סיסמה

ואז צ'קבוקס: **"ההורה שלי יודע שאני פותחת חנות"** — לא הסכמה משפטית, תזכורת אמיתית.

בסיום: מייל להורה — "נפתחה חנות בשם X. הלינק לניהול: … כדי לסגור אותה, השיבי למייל."
זו הבקרה ההורית היחידה ב-v1, והיא מספיקה.

**התחברות:** אימייל + סיסמה, session ארוך (30 יום+). ההתחברות קורית פעם אחת ואז כמעט אף פעם — אל תבני זרימת magic link שדורשת את הטלפון של ההורה בכל כניסה.

## 5. הדשבורד — 3 מסכים

ניווט תחתון, mobile only. אין דסקטופ ב-v1.

### 5.1 הזמנות · מסך הבית

כרטיסים, החדשות למעלה.

```
┌──────────────────────────────┐
│ #7 · לפני 5 דקות        חדש │
│ 🧸 סקוויש חד-קרן × 2         │
│ 🍩 סקוויש דונאט × 1          │
│ ─────────────────────────    │
│ סה"כ ₪45                     │
│ [ שולם ]        [ פתחי צ'אט ]│
└──────────────────────────────┘
```

- `שולם` → סטטוס `paid`, הכרטיס נצבע
- ואז מופיע `נמסר` → `delivered`, הכרטיס עובר לארכיון
- swipe שמאלה → `cancelled`
- `פתחי צ'אט` — חוזר לוואטסאפ עם אותה שיחה

**מצב ריק:** "עוד לא הגיעו הזמנות. שלחי את הלינק לחברות שלך 👇 [העתקת לינק]"

### 5.2 מוצרים

רשת 2 עמודות. `+` צף.

הוספת מוצר = בוטום-שיט אחד:
1. תמונה (מצלמה / גלריה)
2. שם
3. מחיר
4. שמירה

זהו. בלי תיאור, בלי קטגוריות, בלי SKU. לחיצה ארוכה = גרירה לסידור. לחיצה = עריכה, כיבוי, מחיקה.

### 5.3 החנות שלי

**זה המסך שמחזיק את המוצר.** הכיף הוא לעצב חנות, לא לנהל מלאי.

- שם ואמוג'י
- משפט תיאור
- **בחירת ערכת נושא** — 6 אפשרויות, כל אחת עם שם ותצוגה מקדימה חיה
- תמונת כותרת (אופציונלי)
- למטה: לינק החנות + `העתקה` + `שיתוף בוואטסאפ`

תצוגה מקדימה חיה בראש המסך, מתעדכנת תוך כדי. לא preview בכפתור נפרד.

## 6. החנות הפומבית

`/s/{slug}` — עמוד יחיד, ללא הרשמה.

```
┌──────────────────────────────┐
│         🦄                    │
│    החנות של תמר              │
│  סקווישים הכי רכים בעולם     │
├──────────────────────────────┤
│ ┌────────┐  ┌────────┐       │
│ │ תמונה  │  │ תמונה  │       │
│ │ חד-קרן │  │ דונאט  │       │
│ │  ₪15   │  │  ₪12   │       │
│ └────────┘  └────────┘       │
├──────────────────────────────┤
│  🛒 3 פריטים · ₪45  [ הזמנה ]│  ← sticky
└──────────────────────────────┘
```

**לחיצה על מוצר** → בוטום-שיט: תמונה גדולה, שם, מחיר, בורר כמות, `הוספה לסל`.

**לחיצה על "הזמנה"** → בוטום-שיט סיכום:
- רשימת פריטים + סה"כ
- שדה `הערה (לא חובה)` — "אפשר בורוד?"
- הודעה קטנה: **"ההזמנה תיפתח בוואטסאפ. שם תסכמו תשלום ומסירה."**
- כפתור ראשי: `שליחה בוואטסאפ`

**פוטר:** "החנות של תמר · נבנתה בדוכן" → לינק להרשמה. זו כל התפוצה שלך.

## 7. פלואו ההזמנה — מקצה לקצה

```
קונה לוחצת "שליחה בוואטסאפ"
        ↓
POST /api/orders  { slug, items, note }
        ↓
השרת: מאמת מחירים מול ה-DB   ← לא סומכים על הלקוח
        ↓
השרת: כותב שורה  status = 'sent'
        ↓
השרת: מחזיר { orderNumber, phone }
        ↓
הלקוח: בונה טקסט → window.location = wa.me/...
        ↓
וואטסאפ נפתח עם ההודעה מוכנה
        ↓
הילדה רואה "#7 · חדש" בדשבורד
```

**ההודעה:**

```
היי תמר! 👋
ראיתי את החנות ואני רוצה להזמין:

• סקוויש חד-קרן × 2 — ₪30
• סקוויש דונאט × 1 — ₪12

סה"כ: ₪42
הערה: אפשר בורוד?

הזמנה #7
```

### שתי נקודות קריטיות

**המספר לא יושב ב-HTML.** הוא מוחזר מהשרת רק בלחיצה, אחרי יצירת ההזמנה. הוא לא ב-`href`, לא ב-props, לא בקוד המקור. זה לא מונע מאדם נחוש לראות אותו — זה מונע איסוף סיטונאי ע"י crawlers.

**הזמנות רפאים.** הקונה יכולה ללחוץ ולא לשלוח את ההודעה בפועל. לכן הסטטוס הראשוני נקרא `sent` ולא `confirmed`, ויש swipe לביטול. אל תתייחסי ל-`sent` כאל התחייבות.

## 9. כיוון עיצובי

**הקהל הוא בת 11 שרוצה שהחנות תרגיש כמו שלה.** לכן:

הזהות של המוצר עצמו — הדשבורד — צריכה להיות **שקטה**. רקע לבן, טיפוגרפיה נקייה, אפור עדין. כל הצבע הולך לחנויות עצמן. אם הדשבורד צועק, כל החנויות נראות אותו דבר.

**6 ערכות נושא עם שמות, לא עם קודי צבע.** לכל אחת: רקע, צבע ראשי, גופן כותרת, עיגול פינות.

| ערכה | אופי |
|---|---|
| ענן | תכלת רך, פינות עגולות מאוד |
| תות | ורוד־אדום, גופן עגלגל |
| לילה | כהה עם ניאון |
| פסטל | קרם ומנטה |
| ממתק | פסים ורוד־צהוב |
| מינימל | לבן, שחור, בלי קישוט |

**Signature:** התצוגה המקדימה החיה במסך "החנות שלי" — הילדה בוחרת ערכה והחנות משתנה מולה בזמן אמת. זה הרגע שגורם לה להישאר.

**מיקרו־אינטראקציה אחת בלבד:** אנימציית confetti קצרה כשמסמנים הזמנה כ"נמסר". שום דבר אחר לא זז.

**כתיבה:** גוף שני נקבה, פשוט, בלי ילדותיות מזויפת. "עוד לא הוספת מוצרים" ולא "אופס! נראה שהחנות שלך ריקה 😱".

## 10. בטיחות ופרטיות — קבוע בקוד

- `slug` אקראי. לא `/tali`, לא שם בית ספר.
- `<meta name="robots" content="noindex, nofollow">` על כל דף חנות. אין sitemap.
- **אין שדה כתובת. בשום מקום.** מסירה מסוכמת בוואטסאפ.
- `parent_phone` חובה בהרשמה. לא מוצג בחנות — קיים כדי שיהיה למי לפנות.
- דירוג הזמנות: מקסימום 5 הזמנות ל-IP לחנות ליום.
- אין תגובות, אין דירוגים, אין צ'אט פנימי, אין פרופיל ציבורי. הערוץ החברתי היחיד הוא וואטסאפ.
- אדמין יכולה להעביר חנות ל-`paused` מיידית. `paused` = הדף מציג "החנות סגורה כרגע".
- העלאת תמונות: רק image/*, מקסימום 5MB, דחיסה בצד לקוח.

## 11. סטאק

- **Next.js** (App Router) — SSR לדפי החנות
- **Supabase** — Postgres, Auth, Storage
- **RLS** — כל טבלה. ילדה רואה רק את החנות שלה. החנות הפומבית נקראת דרך service role בשרת.
- **Tailwind** — ערכות נושא כ-CSS variables ברמת השורש של דף החנות
- **Vercel**

**נקודה שנוטים לפספס:** נרמול טלפון בשמירה, לא בשליחה. אמא תקליד `050-123-4567`. המירי ל-`972501234567` וצרי תצוגה מקדימה של הכפתור בהגדרות כדי שהיא תראה שזה עובד. זו נקודת הכשל מספר 1 בפלואו הזה.

## 14. איך יודעים שזה עובד

תני את זה לשלוש ילדות. אחרי שבוע:

- **כמה מהן הוסיפו מוצר בלי שביקשת?** ← זה המדד היחיד שחשוב
- כמה חנויות קיבלו הזמנה אחת לפחות
- כמה הזמנות `sent` הפכו ל-`paid` (אם היחס נמוך — יש הרבה הזמנות רפאים, וצריך לחשוב מחדש על הכפתור)

אם אף אחת לא נגעה בזה אחרי היום הראשון — למדת משהו זול מאוד, ולא בנית מערכת סליקה בשביל זה.
