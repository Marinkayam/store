# בדיקות מקצה לקצה

**למה התיקייה הזו קיימת:** הבדיקות ישבו בתיקיית עבודה זמנית מחוץ לריפו,
והסביבה אתחלה את עצמה ומחקה אותן — פעמיים. קוד האפליקציה שרד כי הוא
ב-git; הבדיקות לא. בדיקה שאובדת היא בדיקה שלא הייתה.

מכאן והלאה: **כל בדיקה חדשה נכנסת לכאן ומגיעה ל-git באותו קומיט של
הפיצ'ר שהיא בודקת.**

## מה יש כאן

| קובץ | מה נבדק |
|---|---|
| `stickers.mjs` | מדבקות: הבחירה, מה נשמר בעמודה ומה נגזר ממצב, הרשימה הסגורה, הפינות בגלריה, והרגע החד-פעמי |
| `supashim.mjs` | שים מקומי תואם-Supabase לאימות. **לבדיקות בלבד** |
| `sms-helper.mjs` | קריאת קוד האימות מהשים והזנתו |

## הרצה

צריך סטאק מקומי חי: Postgres 5433 · PostgREST 3001 · supashim 8000 ·
s3shim 9000 · smsshim 9100 · Next 3777.

```bash
node e2e/stickers.mjs
```

## הכלל שחוזר בכל הבדיקות כאן

**בדיקה שתמיד עוברת היא לא בדיקה.** כל חבילה כאן נבדקה גם בכיוון
ההפוך — שהיא באמת נכשלת כשהתנהגות נשברת. `stickers.mjs` תפסה כך באג
אמיתי: כיבוי מדבקה בעורך נראה שמור במסך וחזר בטעינה הבאה, כי
`stickers` לא נכלל ב-update.
