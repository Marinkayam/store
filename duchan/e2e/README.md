# בדיקות מקצה לקצה

**למה התיקייה הזו קיימת:** הבדיקות ישבו בתיקיית עבודה זמנית מחוץ לריפו,
והסביבה אתחלה את עצמה ומחקה אותן — פעמיים. קוד האפליקציה שרד כי הוא
ב-git; הבדיקות לא. בדיקה שאובדת היא בדיקה שלא הייתה.

מכאן והלאה: **כל בדיקה חדשה נכנסת לכאן ומגיעה ל-git באותו קומיט של
הפיצ'ר שהיא בודקת.**

## מה יש כאן

כל קובץ `.mjs` בתיקייה הזו הוא חבילה שרצה לבדה. כל מה שאינו חבילה יושב
ב-`helpers/` — כך הרַצָּן לא צריך רשימת חריגים, והוספת חבילה חדשה לא
דורשת לזכור לרשום אותה איפשהו.

| חבילה | מה נשמר |
|---|---|
| `squish-collection.mjs` | האוסף שייך לילדה: פריטים, מדיה, מדבקות, אהוב, ושהאוסף לא דולף למי שאינה במעגל |
| `squish-circle.mjs` | קישורי הזמנה, קשר סימטרי, הסרה, חסימה, השהיה, תוקף ותקרה |
| `squish-discover.mjs` | "לגלות" והגלריה עונים אותה תשובה, ורק פריטים פתוחים לטרייד מוצגים |
| `squish-trades.mjs` | המסע המלא: הצעה · צמצום · אישור · שמירה אטומית · וואטסאפ · השלמה |
| `squish-safety.mjs` | יציאה: חסימה, השהיה, ביטול מנהלת, דיווח, הגבלות קצב ומחיקת חשבון |
| `invite-safety.mjs` | הפערים שנסגרו במיגרציה 0032, אחד-אחד |
| `stickers.mjs` | מדבקות: הבחירה, מה נשמר ומה נגזר, הרשימה הסגורה, והרגע החד-פעמי |
| `helpers/index.mjs` | `check` · `wipe` · `asUser` · `newCollector` · `makeInvite` · `joinCircle` |
| `helpers/sms.mjs` | קריאת קוד האימות מהשים והזנתו |
| `fixtures/` | מדיה אמיתית להעלאות. נכנסת ל-git — בדיקה שתלויה בקובץ מקומי היא בדיקה שתיפול אצל מישהי אחרת |

החוזים עצמם — מה אסור שיישבר ולמה — יושבים ב-`docs/squish-e2e-contracts.md`.

## הרצה

צריך סטאק מקומי חי: Postgres 5433 · PostgREST 3001 · supashim 8000 ·
s3shim 9000 · smsshim 9100 · Next 3777.

```bash
npm run test:e2e:squish          # שבע החבילות, בסדר קבוע
npm run test:e2e                 # הכל
node scripts/e2e.mjs squish-trades   # חבילה אחת
```

> `npm run build` דורס את ה-`.next` של שרת הפיתוח. אחרי בילד תמיד
> להפעיל מחדש את `npm run dev`, אחרת הדפים יחזירו 200 אבל ה-JS יחזיר
> 404 ו-React לא יתעורר.

## הכלל שחוזר בכל הבדיקות כאן

**בדיקה שתמיד עוברת היא לא בדיקה.** `check()` דורש ערך בוליאני וזורק
על כל דבר אחר, כדי שבדיקה שנכתבה רשלנית תיפול ברעש ולא תעבור בשקט.

כל חבילה נבדקה גם בכיוון ההפוך — שהיא באמת נכשלת כשההתנהגות נשברת.
כך נתפסו באגים אמיתיים: `stickers.mjs` תפסה שכיבוי מדבקה בעורך נראה
שמור וחזר בטעינה הבאה כי `stickers` לא נכלל ב-update, ו-`squish-trades`
תפסה ש-`accepted_by_sender_at` נעלם בשכתוב — ובלעדיו שום טרייד לא היה
מגיע לשמירה.
