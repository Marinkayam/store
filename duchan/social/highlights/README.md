# הייליטס לאינסטגרם

**סטטוס:** חי. כל ההייליטס מראים רק פיצ'רים שכבר באתר החי.

9 הייליטס. בכל אחד: סטורי פתיחה מונפש (`-0-opener`), ואחריו סטוריז בקול של מרינה עם כתוביות צרובות. כל סטורי 1080×1920, 3–8 שניות.

**סדר העלאה:** לכל הייליט, לפי המספר בשם הקובץ: `0-opener`, ואחריו 1, 2, 3. הכיסוי של כל הייליט ב-`covers/` (`-square` לבחירת כיסוי).

**הערה לבוט:** אינסטגרם לא מאפשר ליצור הייליטס או לבחור כיסוי דרך API. ההייליטס עצמם נבנים מהטלפון. אפשר לפרסם את הסטוריז האלה גם כסטוריז רגילים.
