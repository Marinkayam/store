# השוק של השכונה

**סטטוס:** חי

## מה זה
הדוכן עומד ליד הדוכנים של ילדים מהשכונה. בוחרים עיר ושכונה מהרשימה, ההורים מאשרים בלינק, ואז רואים את הדוכנים של השכנים ומזמינים עוד שכנים לפתוח דוכן.

## למה זה עוזר
- קונים קרובים: שכנים, בלי משלוחים.
- השוק גדל כשמזמינים חברים מהשכונה.

## בטיחות
- ההורים מאשרים לפני שהדוכן נכנס.
- את השוק רואים רק דוכנים מאותה שכונה שההורים שלהם אישרו.
- רואים רק את שם הדוכן והמוצרים. בלי שם, בלי טלפון, בלי רחוב ובלי כתובת.
- שכונה שלא ברשימה: ההורים כותבים את השם, ואנחנו בודקים אותו לפני שהיא נוספת.
- הלינק להזמנת שכנים לא מגלה איזו שכונה זו.

## איך משתמשים
1. במסך ההזמנות «חדש: השוק של השכונה», או ב«הדוכן שלי» ← «השוק של השכונה».
2. בוחרים עיר ושכונה.
3. שולחים להורים את הלינק לאישור.
4. «להזמין שכנים».

## צילומי מסך
אין עדיין. רק עם נתוני הדגמה.
